# Perpustakaan Sekolah Digital - UKK RPL Paket 4 (2025/2026)

Aplikasi Web Peminjaman Buku Perpustakaan Sekolah Digital dibuat dengan bahasa pemrograman **Rust** (**Axum + Tokio + SQLite**) dan antarmuka web modern responsif (HTML5, Vanilla CSS Glassmorphism, JS Fetch API).

## 🚀 Cara Menjalankan Aplikasi

1. **Jalankan Backend Server Rust:**
   ```bash
   cargo run
   ```
2. **Akses Aplikasi di Browser:**
   Buka URL: [http://localhost:3000](http://localhost:3000)
